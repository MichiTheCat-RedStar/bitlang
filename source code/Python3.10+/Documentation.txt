BitLang - довольно простой язык со своими командами

Но каждая переменная в нём должна быть объявлена перед инициализацией через функции, кроме объявления!

Например:
```bl
a += 5;  // Ошибка!
print a; // Фатальная ошибка!
// --------------------------
a = 0;   // 0
a += 5;  // 5
print a; // Отображает 5
```

Этот принцип работает и с input или прочими функциями!

input возвращает int

--- Всё переписать ---

	Типы:

Строка - текстовая информация, которая объявляется в двойных кавычках, напрмиер "Привет, BitLang!";

Число - информация в виде чисел, включающая числа от 0-9, так же может быть отрицательным;

Булево - число от 0 до 1, но задаётся через true для 1 и false для 0 соответственно;

Переменная - тип данных для хранения значения;

	Функции:

Стоит уточнить, что тут в примерах функции без ";" в конце, в коде их ставить обязательно!;

print - используется для отображения значений указанных выше, так же имеет аналог в виде print! для того, чтобы отображать значения без перевода строки, используется как {print переменная};

арифметика (+=, -=, *=, /=) - для изменения переменной, используется как {переменная знак значение}, например a += 12, но важно уточнить, что a дожно быть объявлено ранее, причём как тип числа;

присвоить - для того, чтобы объявить переменные, например {name = "Имя"};

комментарии - это просто возможность писать что угодно после "//";

if - это условие, задаётся как {if условие:} - это создаёт область видимости, которая исполняется, если условие внутри верно;

end - нужно для того, чтобы закрыть область видимости, например:	/
```bl																/
a = 5;																/
if a:																/
	print "Условие выполнено!";										/
end;																/
```;

else - если не сработало if, то будет вызвано то, что в области видимости	/
else, например:																/
```bl																		/
a = 0;																		/
if a:																		/
	print "Условие выполнено!";												/
else:																		/
	print "Условие не выполнено!";											/
end;																		/
```;

elif - находится между ними, он вызывается, если не сработал if;

while - цикл, например:		/
```bl						/
a = 5;						/
while a:					/
	print! a;				/
	a -= 1;					/
end; 						
```;

Так же есть stop и skip для остановки работы цикла и пропуска шага цикла;

not - нужно для того, чтобы превращать 0 в 1, а 1 в 0, нужно для bool перемнных;

input - нужно для того, чтобы задать значение в виде числа, например {input a};

random - нужно для того, чтобы задать случайное значение числа, например {random a};

Все блоки, заканчивающиеся ":" вместо ";" должны закрываться с помощью "end";
