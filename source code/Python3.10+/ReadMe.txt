Я решил сделать свой ЯП, не опять, а с более просто правильных подходом...
Это минималистичный язык на Python, интерпретируемый в C и компилируемый через GCC

ReadMe ещё сырой, позже я допишу его более конкретно, так же как и сырой ЯП, однако стараюсь делать его уже рабочим!

Тут есть:				Синтаксическое представление:
	Типы:
		Переменная		[a-zA-Z_][a-zA-Z0-9_]*
		Число			-?\d+
		Строка			".*"
		Булево			(true|false)
	Функции:
		Вывод			print *;
		Отображение		print! *;
		Присвоение		* = *:
		Прибавить		* += *;
		Отнять			* -= *;
		Умножить		* *= *;
		Разделить		* /= *;
		Остаток			* %= *;
		Условие			if *:
		Иначе			else;
		КонецУсловия	end;
		Комментарии		//*
		Цикл			while *:
		Подсчёт			for *..*:
		Ввод			input *;
		Импорт			importC *;
		Не				not *;
		ИначеЕсли		elif *:
		Продолжить		skip;
		Прервать		stop;
		Случайность		random *;
